# Swing Trade Rank

Swing Trade Rank is a quantitative equity-research project for testing whether sector-relative momentum can rank liquid U.S. stocks by their future 10-trading-day sector-relative returns.

The first milestone is EXP-001: a leakage-aware, weekly relative-momentum baseline. It produces decile return results and Spearman Rank IC, with all timing assumptions and data limitations documented.

This is research software—not a trading platform or investment advice. See [AGENTS.md](AGENTS.md) for the research rules and current implementation scope.
